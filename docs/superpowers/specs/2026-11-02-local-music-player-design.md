# 本地音乐播放器 · 设计文档

日期：2026-11-02
状态：待构建

## 1. 背景与意图

用户使用 macOS 13.7.8（Intel），本地音乐约 115 个文件、889MB，主要集中在 `~/Music`，格式以 mp3 为主，另有 m4a/m4r/wav/flac/mp4。现有本地播放器要么不支持这台机器，要么资源占用高、界面过时。用户怀念千千静听：本地库管理、歌词、迷你模式、换肤、低资源。

真正的使用场景是**工作时的背景音乐**：启动快、常驻后台、不抢注意力；偶尔需要看歌词跟唱，歌词要浮在桌面上但不挡工作。

成功的样子：
- 打开应用、导入 `~/Music`，一秒内看到歌曲列表并可播放。
- 空闲时不占 CPU，内存几十 MB，不发热、不拖慢机器。
- 工作时缩成迷你条或用菜单栏控制，不用切回主窗口。
- 歌词窗浮在桌面上，磨砂半透明、可调大小，锁定后不挡鼠标操作。
- 下载来的歌曲标签乱码能一键修好，标签能手动编辑。
- ape、dsf 等系统不支持的格式也能播放（后台转码缓存）。

## 2. 目标 / 非目标 / 反目标

### 目标
1. 导入本地文件与文件夹，递归扫描，读取标签、封面、时长。
2. 播放列表管理：全部音乐、按文件夹分组、手动播放列表、搜索、排序、拖拽、随机/循环。
3. 原生播放，支持系统媒体键，低资源。
4. 桌面歌词：同名 .lrc 优先，其次在线匹配，再次手动导入；磨砂悬浮、置顶、可锁定穿透、可缩放。
5. 迷你模式与菜单栏常驻。
6. 三套内置皮肤（磨砂玻璃为统一底材质）。
7. 标签编辑与乱码修复，支持批量。
8. 按标签手动整理文件（预览 + 撤销）。
9. 系统不支持的格式通过 FFmpeg 解码并缓存为 ALAC，后台队列进行。

### 非目标（v1 不做）
- 在线音乐、流媒体、播客、视频播放。
- 云同步、账号、社交分享。
- Windows / Linux 版本。
- CD 抓取、录音、音效均衡器。
- 第三方皮肤包格式（.skn 之类）与皮肤编辑器。
- 后台自动整理文件。
- 整库批量转码/导出（转码仅用于播放缓存）。
- 标签在线上数据库自动补全（只做本地编辑与乱码修复）。

### 反目标（做成这样就算失败）
- 占用高、启动慢、播放时风扇转。
- 界面元素抢注意力，或歌词遮住工作窗口且无法穿透。
- 改动用户文件却没有预览、备份或撤销。
- 断网时核心播放功能不可用。

## 3. 约束

- 原生应用，Swift 5.8 / SwiftUI + AppKit，最低 macOS 12，Intel 与 Apple Silicon 通用二进制。
- 中文界面。
- 开发环境：Xcode 14.3.1，macOS 13.7.8 Intel。
- 第三方依赖仅允许：TagLib（标签读写，编译为静态库随应用链接）、FFmpeg（仅转码兜底，使用本机 CLI，不随包分发）。需附许可证说明。
- 不使用数据库；索引与设置用 JSON 存在 Application Support。
- 联网仅用于歌词匹配；断网时其余功能完整可用。
- 应用名：**声屿**（内部模块与 Bundle ID 用 `SoundIsle`）。

## 4. 技术方案

### 4.1 总体结构

- SwiftUI 负责主窗口、迷你窗、歌词窗、设置界面；AppKit 负责无边框透明窗口、置顶层级、鼠标穿透、菜单栏图标（NSStatusItem，因为最低支持 macOS 12，不用 MenuBarExtra）。
- 播放使用 AVAudioEngine + AVAudioPlayerNode；在混音节点上挂 tap 做 FFT（Accelerate/vDSP），驱动频谱。
- 音乐库索引、播放列表、设置、歌词缓存、编辑撤销记录均为本地 JSON。
- 扫描、标签读取、转码、在线歌词查询全部异步，不阻塞 UI。

### 4.2 格式支持

原生（AVFoundation 直接播放）：
mp3、m4a/aac/alac、wav、aiff、flac、mp4（音频）等系统支持格式。

兜底（FFmpeg 解码）：
ape、wma、ogg/opus、wv、tta、dsf/dff 等系统不支持的格式。

处理方式：
- 首次遇到不支持格式时，用 FFmpeg CLI 解码并编码为 ALAC（.m4a）缓存，放在 `~/Library/Application Support/SoundIsle/transcode/`。
- FFmpeg 查找顺序：设置中手动指定的路径 → `/usr/local/bin/ffmpeg` → `/opt/homebrew/bin/ffmpeg` → `PATH`。设置页提供自动检测、选择文件、重新检测。
- 缺失时不阻塞播放：原生格式照常可用；非原生文件仍可被扫描和收录（标题用文件名，时长暂记 0）；点播时显示明确提示与 `brew install ffmpeg`、复制命令、重新检测、手动选择路径入口。
- 缓存键 = 原文件路径 + 文件大小 + 修改时间 + 转码参数版本。
- 扫描完成后启动低优先级后台队列转码；当前正在播或即将播的歌曲插队。
- 若用户点播尚未转码的歌，显示"正在准备…"并现场转码；其余情况无感。
- 原始文件永不因播放被修改。
- 设置页可查看缓存占用并清理。

### 4.3 标签

- 统一用 TagLib 读取和写入：ID3v1/v2、FLAC/Vorbis、MP4、APE 等。
- 可编辑字段：标题、歌手、专辑、专辑歌手、年份、曲目号、流派、封面。
- 批量编辑：多选后修改某个字段，应用到全部（留空表示不修改该字段）。
- 乱码修复：检测"UTF-8/GBK 字节被当作 Latin-1 解码"的典型乱码，给出还原预览，确认后写回；同时允许全字段手动修改。
- 写回原文件；写入前把旧字段值存入撤销记录（保留最近 50 次编辑，持久化）。支持撤销。
- 某格式不支持写封面时，封面控件禁用并说明原因。
- 读取失败或文件损坏时记入"无法读取"列表，不阻塞其他歌曲。

### 4.4 按标签整理文件

- 仅手动触发：选中歌曲 → 选择模板 → 预览"原路径 → 新路径"表格 → 确认执行。
- 模板变量：`{artist}` `{album}` `{albumartist}` `{title}` `{track}` `{year}` `{ext}`；内置几个模板（如 `歌手/专辑/曲目 歌名`、`歌手 - 歌名`）。
- 非法字符替换，未知字段用"未知歌手/未知专辑"或跳过该层级（可在模板里选择）。
- 同名冲突自动加编号，绝不覆盖。
- 可选"移动"或"复制到新位置"；跨磁盘移动先复制再询问是否删除源文件。
- 每次整理记录原路径清单，支持一键撤销（移回原位置）。
- 默认关闭，不做后台自动整理。

### 4.5 音乐库与播放列表

- 导入：拖入文件/文件夹，或菜单选择。递归扫描，支持扩展名白名单（含上述原生与兜底格式）。
- 标签缺失时按文件名推断：`歌手 - 歌名`、`歌名-歌手`、`曲目号 歌名` 等模式；仍推断不出就用文件名作标题。
- 索引持久化，记录路径、大小、mtime、标签、时长、封面缓存、歌词缓存。
- 启动时对已导入目录做增量扫描（按 mtime/size 判断变化）；提供手动"重新扫描"。不实现文件系统实时监听。
- 文件消失时标记为"缺失"，提供定位/移除操作。
- 播放列表：
  - 系统列表：全部音乐、最近添加、按导入文件夹分组。
  - 用户播放列表：新建、重命名、删除、拖入歌曲、内部拖拽排序。
  - 搜索（标题/歌手/专辑/文件名）与按列排序。
- 播放模式：顺序、列表循环、单曲循环、随机。
- 记住上次的队列、当前歌曲与播放位置；启动后恢复但**不自动播放**。
- 快捷键：空格播放/暂停，左右方向键快退/快进，⌘F 搜索；系统媒体键通过 MPRemoteCommandCenter 接管。

### 4.6 播放与频谱

- AVAudioEngine + AVAudioPlayerNode，支持 seek、音量、静音。
- 在混音节点 tap 上取 PCM，用 vDSP 做 FFT，输出约 24–32 段频谱，刷新约 30fps，带衰减平滑。
- 频谱显示位置：迷你条内嵌（默认）；主窗口播放条底部淡波（设置里可开关）；歌词窗不加。
- 播放时目标 CPU < 3%，空闲目标 < 1%。

### 4.7 菜单栏与迷你模式

- 菜单栏常驻图标，菜单显示当前歌曲、播放/暂停、上一首/下一首、显示迷你窗、显示/隐藏歌词、锁定/解锁歌词、显示主窗口、退出。
- 关闭主窗口不退出应用（菜单栏保留）；设置中可改为"关闭即退出"。
- 迷你模式为横向胶囊窗：封面、歌名/歌手、实时频谱、时间、上一首/播放/下一首、展开按钮、底部细进度条；可拖动、记住位置、可选置顶。
- 迷你窗与主窗口共享同一播放状态，切换即时同步。
- 迷你窗与歌词窗同样跨桌面显示、可在其他应用全屏时浮于其上，并默认从录屏/共享画面中隐藏（受同一个设置开关控制）。

### 4.8 歌词

来源优先级：
1. 用户手动指定或导入的歌词（显式覆盖，记录在曲目上；可"恢复自动"）。
2. 同目录同名 `.lrc`（大小写、括号差异做宽松匹配）。
3. 在线匹配（LRCLIB）：用标题 + 歌手 + 时长查询，命中后缓存到本地。
4. 都没有：显示"暂无歌词"，提供重试匹配与导入入口。

"更换歌词…"入口在歌词窗菜单与主窗口都可用，不限于"暂无歌词"状态；导入 `.lrc` 或纯文本都可，纯文本按行显示、不做时间同步。在线匹配只接 LRCLIB；匹配不到是正常结果，用户可导入 `.lrc`，验收不要求覆盖率达到某个比例。

- 解析：支持 `[mm:ss.xx]` 多时间戳行、`[offset:]`；按时间排序，当前行高亮。
- 歌词窗：
  - 无边框、透明、磨砂背景，默认不透明度约 26%，可在设置/悬浮控件中调整。
  - 始终置顶；**锁定**后鼠标穿透（忽略鼠标事件），不挡后面窗口；未锁定时鼠标悬停显示小按钮：解锁、A−、A+、透明度、关闭。
  - 可拖拽边缘调整大小；**只保存窗口尺寸，字号由宽度映射**（宽 320–900px 对应约 18–36px），拖动时文字跟着缩放。
  - 显示模式：单行（仅当前句）或双行（当前句 + 下一句），可切换。
  - 可选"文字描边"，应对浅色桌面。
  - 记住位置、尺寸、透明度、显示模式、锁定状态。
  - 锁定后虽然鼠标穿透，但解锁入口始终可达：菜单栏菜单和主窗口都提供"锁定/解锁歌词"，菜单栏另有"显示/隐藏歌词"，不会出现无法退出锁定的情况。
  - 跨桌面与全屏：歌词窗和迷你窗随用户切换桌面，并能在其他应用处于全屏时浮在其上（加入所有 Space、允许全屏辅助显示），不单独占用桌面。
  - 录屏与共享：默认在屏幕录制、屏幕共享、截图中隐藏（窗口不参与画面捕获）；设置中提供"录屏时显示"开关。
- 在线查询失败静默处理，不影响播放；可手动重试。

### 4.9 皮肤与视觉

- 磨砂玻璃是统一底材质：半透明面板 + 背景模糊 + 高光描边。
- **主题模型：强调色 × 明暗底**。六套预设各自都有浅色与深色两版：
  - 深空蓝：强调色 深色 `#7AA2FF` / 浅色 `#3E6FE0`（默认皮肤）
  - 晨光橙：强调色 `#C2703D`
  - 墨黑琥珀：强调色 `#F5B942`
  - 青瓷：强调色 `#4FB89A`
  - 莓紫：强调色 `#B48CF2`
  - 海盐：强调色 `#3E8FB0`
- 设置里可开启"跟随系统外观"（默认开）：系统切浅色/深色时自动换底，强调色同时做对比度微调；也可强制固定明暗。
- 另提供自定义强调色取色器；明暗底、选中态、按钮文字颜色自动计算。
- 换肤作用于主窗口、迷你窗、播放条、歌词窗强调色；布局不变。
- 图标系统：统一 20px 网格、1.75 描边、圆角端点；只有播放/暂停为实心，其余线性。
- 播放条比例：中心区固定为 360px 视觉单元，播放键 38px、上一首/下一首按钮 34px（20px 图标）、间距 20px、进度条 4px 与中心列同宽。保证按钮与进度条属于同一组。
- 歌曲列表默认显示序号，当前播放行显示应用自绘的跳动脉冲；可选改为读取内嵌封面显示缩略图。
- 视觉参考稿见附录。

### 4.10 设置

- 音乐文件夹管理（添加/移除/重新扫描）。
- 转码缓存占用与清理、FFmpeg 路径（自动检测 / 手动选择 / 重新检测）。
- 在线歌词开关（默认开）、歌词默认透明度与描边。
- 默认皮肤、跟随系统外观开关、自定义强调色、关闭主窗口行为、迷你窗置顶。
- 歌曲行显示方式（序号 / 封面缩略图）。
- 标签编辑撤销记录清理。

## 5. 数据与文件

- 应用数据目录：`~/Library/Application Support/SoundIsle/`
  - `library.json`：曲目索引、导入文件夹（可重建的缓存，损坏时重建）。
  - `playlists.json`：用户创建的播放列表（用户数据，独立于索引入口）。
  - `settings.json`：皮肤、歌词、窗口状态等（用户数据）。
  - `lyrics/`：在线匹配与导入歌词缓存。
  - `covers/`：封面缓存。
  - `transcode/`：ALAC 播放缓存。
  - `undo/`：标签编辑与文件整理撤销记录（用户数据，整理记录必须保留）。
- 用户数据（`playlists.json`、`settings.json`、`undo/`）与可重建缓存分开；索引损坏重建时绝不触碰用户数据。
- 所有 JSON 写入采用原子替换（临时文件 + rename），并在每次成功写入后保留上一版 `.bak`；用户数据损坏时优先从 `.bak` 恢复并向用户报告。
- 索引按曲目 ID 引用；文件路径变化由重新扫描修正。

## 6. 性能与体验指标

- 1000 首曲目：启动到列表可交互 < 1.5s（有缓存时）；首次扫描 1000 首 < 5s。
- 空闲 CPU < 1%；播放 mp3 时 < 3%；内存常驻 < 150MB。
- 频谱与 UI 动画不影响音频；滚动列表 60fps。
- 所有耗时操作异步，主线程不阻塞；扫描/转码/歌词查询有进度或状态提示。

## 7. 错误处理

- 无法读取的音频：跳过并在设置里列出，不阻塞扫描。
- 转码失败：标记该文件不可播放，提示原因；可重试。
- 标签写入失败：报告错误，不把文件留成半写状态（支持则写临时副本再替换，不支持则先备份原文件）。
- 在线歌词失败：静默 + 可重试，不影响播放。
- 缓存/索引损坏：忽略并重建曲目索引，保留原音乐文件；播放列表、设置、撤销记录从 `.bak` 恢复，恢复失败时报告而不是静默清空。
- 路径失效：标记缺失，提供重新定位或移除。

## 8. 测试与验收

单元测试（轻量，无框架负担）：
- 文件名标签推断。
- 乱码检测与还原。
- LRC 解析（多时间戳、offset、纯文本）。
- 整理模板的非法字符与字段回退。
- 转码缓存键生成。

集成/手动验收（用真实 `~/Music`）：
- 导入 `~/Music` 与 `红歌`，数量、标题、歌手正确。
- 播放 mp3/flac/m4a/wav；准备一个 ape 或 dsf 样本验证后台转码与点播等待。
- 编辑一首副本的标签、修复一个构造的 GBK 乱码标签、撤销。
- 整理到临时目录，预览正确、可撤销。
- 歌词：放置同名 .lrc 验证优先；无 .lrc 的歌曲在线匹配；手动导入；锁定后鼠标穿透；缩放字号跟随。
- 迷你窗与菜单栏控制；媒体键。
- 切换桌面、在另一个应用全屏时，歌词窗与迷你窗仍在；录屏/共享时默认不出现在画面中，开关可关闭。
- 三套皮肤切换。
- 观察空闲与播放时 CPU/内存。
